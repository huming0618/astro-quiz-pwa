HOW THE NUMBERS ARE MADE

从太阳、地球、月球的位置，算到时刻与可见区。

01 / 星历

日期 → 天体位置

把北京时间换成 UTC，再转换成儒略日。库用 TT（力学时）计算太阳、月球的位置，用 UT 近似地球自转时刻；ΔT 取模型值，UT1 与 UTC 在库中近似视为相同。

02 / 影子

位置 → 月食阶段

在满月附近，求月心离背太阳地影轴最近的时刻作为食甚；再数值求解影轴距离跨过各接触阈值的时刻。库考虑日月距离变化，并给地球有效影半径增加 88 km。

03 / 地平线

地球自转 → 看得见哪里

同一时刻，不同经纬度的地平线不同。将月球赤经、赤纬与格林尼治视恒星时结合，算出时角与高度；月心高度 h > 0° 才记为几何可见。

基础公式：什么时候碰到影子？

把月心投影到地影轴

s = m · â
d = |m − s â|

m 是地心到月心的向量；â 是背太阳方向的单位向量。s > 0 才在背太阳一侧，d 是月心距轴的垂直距离。

月球位置处的影子有多宽？

rᵤ ≈ Rₑ − s(R☉ − Rₑ)/D
rₚ ≈ Rₑ + s(R☉ + Rₑ)/D

D 为日地距离，Rₑ、R☉、Rₘ 为有效地球、太阳、月球半径。上式是近轴影锥关系，不是把上方教学常数拿来预报。

求根得到接触条件

P1 / P4：d = rₚ + Rₘ
U1 / U4：d = rᵤ + Rₘ
U2 / U3：d = rᵤ − Rₘ

库先求食甚，再以食甚处的影半径作为阶段阈值，分别向前、向后数值求根，返回两根间隔的一半。本站按 t = t食甚 ± sd 重建时刻，故是对称近似；不存在的阶段显示“不发生”。

进阶公式：从赤经赤纬，到月球高度与全球边界

H = 15° × (GAST − α) + λ
sin h = sin φ sin δ + cos φ cos δ cos H

φ 为纬度、λ 为东经（西经负），δ 为赤纬；GAST 和赤经 α 在库中是“小时”，乘 15° 后才与经纬角统一单位。赤道坐标都使用当日真赤道/真春分点，不能混用 J2000。h = 0° 是边界，h > 0° 是地平线上方。

上式直接代入地心赤经赤纬会漏掉最大约 1° 的月球地平视差。本站地图先在扁球地球上构造海平面观察者位置 r，然后用月球矢量 m − r 与当地铅直单位向量 n̂ 求 sin h = (m − r)·n̂ / |m − r|；地点读数独立使用库的 Equator + Horizon（不加折射）。两条路径已做数值对照。

地图的太阳夜区也以太阳中心几何高度 < 0° 表示，并不等同于天文暮光结束。月下方向用地心赤纬和 λ = 15°(α − GAST) 标示。地图 1° 栅格、白线插值仅作区域判断；靠近边界请看所选地点的数值高度，不把地图当作精密地形预报。

THE BIG IDEA

月食需要两个条件，同时成立。

01

先是满月

月球位于地球背向太阳的一侧。太阳、地球、月球在天空中的方向接近排成一直线，但还可能有上下偏差。

02

还要靠近交点

月球轨道相对黄道面倾斜约 5.145°。地月相距约 60.3 个地球半径，这一点倾斜就能让满月偏离地影轴约 5.4 个地球半径。

03

于是出现「蚀季」

太阳方向约每半年经过交点线附近，形成可能发生日月食的蚀季。但蚀季不保证一定出现本影月食，还取决于满月时刻与交点的距离。

模型比例、边界与资料

地球半径 = 1，月球半径 = 0.273，地月距离 = 60.3；太阳半径 = 109.1，日地距离 = 23455。太阳在画外，以箭头标示光线方向。本影向背太阳方向逐渐收窄；月球距离处本影半径约 0.72、半影半径约 1.28。

主场景球体、轨道与阴影按上述比例。月球旁的光圈、文字、交点圆环、线宽仅是定位标记，不代表天体尺寸。蓝色圆盘仅帮助识别黄道面。横截面独立自动缩放，月球与影子之间仍保持比例。

采用圆轨道、平均倾角与固定交点，忽略偏心率、交点约 18.6 年的退行、视差及大气折射。月食类型用球面横截面的近似圆盘重叠判定，不是星历或真实月食日期预报。「下一个满月」推进到下一次黄经差 180° 的模型时刻；「移到满月」仅改变月球位置以便比较。
